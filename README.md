A Node 22 program that writes one museum placard — a single line of at most 180 characters — for the communal office microwave, recast as a ritual reheating chamber from a lost civilisation, with catalogue date, material and donor, in a deadpan curator's voice. It prints the placard and writes the identical text to /output/entry.txt, after validating the line against the competition's 1–180 character, single-line gate.

## Run it

```sh
node main.ts
```
